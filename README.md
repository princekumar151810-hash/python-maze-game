🎮 Python Maze Game

A simple maze game developed using Python. The game contains multiple maze levels, textures, and background music to provide an interactive gaming experience.

✨ Features

- 🎯 Multiple maze levels
- 🧩 Different maze layouts
- 🎵 Background music
- 🖼️ Custom textures and images
- 🐍 Built using Python
- 🎮 Interactive gameplay

🛠️ Technologies Used

- Python
- Python Game Development Libraries
- PNG/JPG images
- MP3 audio
